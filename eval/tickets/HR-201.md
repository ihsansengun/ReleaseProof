# HR-201 Manager decisions update the leave balance

Synthetic ticket for demonstration app B.

## Acceptance criteria

- REQ-1 An employee sees their remaining leave days on the "My time off" screen.
- REQ-2 Submitting a request does not change the remaining days while the request is pending.
- REQ-3 When a manager approves a request, the requested number of days is deducted from the employee's remaining days.
- REQ-4 When a manager rejects a request, the employee's remaining days do not change.
- REQ-5 The number of days in a request is the count of calendar days from the first day to the last day, inclusive.
